# Corel AI Operatörü 1.0.0

Corel AI Operatörü is a Windows control centre for CorelDRAW 2026. You describe a job in Turkish, or attach
a reference, review the plan it proposes, and it carries the plan out in your open CorelDRAW as ordinary,
editable objects.

## What v1.0 does

- **Natural-language editing.** "Logoyu yüzde 15 küçült, başlığı ortala" becomes a list of typed steps you
  review before anything runs. Destructive steps ask for confirmation; every plan is one Ctrl+Z.
- **Reference reconstruction.** A JPG, PNG, PDF, SVG or CDR is analysed and rebuilt at the physical size you
  give (for example 500 × 700 mm) as native shapes and editable text. Vector files are imported with their own
  objects instead of being redrawn.
- **Compare and improve.** *Referansla Karşılaştır* measures the result against the reference (position, size,
  text, colours, page size). *Otomatik İyileştir* corrects the measured differences in at most three passes.
- **Production check.** *Üretim Kontrolü* reports page size, objects outside the page, missing fonts, low
  bitmap resolution, unresolved placeholders, uncertain text and missing files before you produce anything.
- **Outputs.** CDR, PDF, PNG and SVG.
- **Automations and batches.** Save a finished job as a reusable automation with variables and simple
  arithmetic (`{{GENISLIK / 2}}`), then run it for every row of a CSV or Excel (.xlsx) file, with a worksheet
  selector for Excel.
- **Turkish interface**, with Turkish and Arabic text handled as Unicode end to end.

## Requirements

- Windows 10 or 11, 64-bit.
- CorelDRAW 2026 (not included). Keep it open on screen while you work.
- No .NET installation is needed; the package is self-contained.
- For AI features: an API key for the configured provider (Anthropic).

## Installation

- **Installer:** run `CorelAI-Operator-1.0.0-Setup.exe`. It installs for the current user, without
  administrator rights, adds a Start Menu entry and offers a Desktop shortcut.
- **Portable:** extract `CorelAI-Operator-1.0.0-win-x64.zip` anywhere and run `CorelSignStudio.App.exe`.

Uninstalling removes the program and its shortcuts. Your settings, automations, history and logs under
`%LOCALAPPDATA%\CorelSignStudio`, and your outputs under `Documents\Corel AI Operatörü`, are left in place.

## AI configuration

Open **Ayarlar > Yapay Zekâ**, choose the provider and model, paste your API key and press **Kaydet**, then
**Bağlantıyı Test Et**. The key is encrypted for your Windows account (DPAPI) and is never written to logs or
to the project folder. Without a key the built-in planner still understands a fixed set of typed commands,
and everything that does not need AI (automations, batches, comparison by measurement, the production check)
keeps working.

## Main workflow

1. Open CorelDRAW, open Corel AI Operatörü, press **Bağlan**.
2. Type a request, or add a reference and write the size you want.
3. **Planı Hazırla**, read the proposed steps, then **CORELDRAW'DA UYGULA**.
4. **Referansla Karşılaştır**, **Otomatik İyileştir**, **Üretim Kontrolü**.
5. Save or export, and optionally **Otomasyon Olarak Kaydet** to reuse the job.

## Automation and Excel

In **Toplu İşler** pick an automation and a data file. The first row holds the variable names. For Excel,
choose the worksheet; cells are read as displayed, so `001` stays `001`. Existing files are never overwritten —
a second output with the same name gets `_002`.

## Safety

- The AI only proposes typed actions from a fixed list. It cannot run code, scripts, macros or COM calls.
- Every plan is shown before it runs and can be undone in CorelDRAW with one Ctrl+Z.
- Automatic improvement never deletes anything and stops after three passes.

## Privacy

- Only what you choose is sent to the AI provider: your request, the names, texts and sizes of the objects in
  the open document, and a reference image when you press **Referansı Analiz Et** or compare with AI
  configured. Vector references (SVG, CDR, single-page PDF) are not sent.
- There is no telemetry and no update service.

## Tested on

Windows 11, .NET 8, CorelDRAW 2026 (27.2, trial). The release acceptance run (`build\acceptance.ps1`) covers the
unit suite, the real-CorelDRAW suites, the published executable's self-test with and without CorelDRAW, and
the portable ZIP. See the acceptance summary attached to the release for the exact results, including which
steps were skipped on the release machine.

## Known limitations

- Photographs, paintings and detailed illustrations are not vectorised; they need a source file, a bitmap crop
  or a placeholder.
- Fonts are matched approximately and reported as exact, likely or fallback; exact identification is not
  guaranteed.
- Differences that only the vision model sees are advisory; only measured differences are corrected.
- Rotation and font weight are not compared.
- Merged table cells are reported, not reproduced. Arrow heads are not drawn.
- Arabic and other right-to-left text is preserved exactly and drawn in a font that has the glyphs, but
  right-to-left paragraph typography is not tuned; check it in CorelDRAW.
- A single-page PDF keeps its vectors. A chosen page of a multi-page PDF is redrawn from its picture.
- Edits apply to the active page.
- Batch data is `.csv` or `.xlsx`; the old `.xls` format is not supported.
- A CorelDRAW that is busy or showing a dialog blocks automation until the dialog is closed. With the
  CorelDRAW **trial**, an instance started hidden by automation can be blocked by trial dialogs, so always
  work with CorelDRAW open on screen.
- The interface language is chosen at start-up (Turkish) and cannot be switched while running.
